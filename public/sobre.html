// sobre o bar

JILL-11.BAR

"Todo mundo que vem aqui tem uma história. Eu só fico aqui atrás servindo drinks e ouvindo."

// o que é isso

Um blog inspirado no jogo VA-11 Hall-A. Um lugar pra escrever o que você quiser. Sinta-se livre.

// como funciona

Crie uma conta, escreva seus posts e se quiser adicione uma música do seu gosto usando o Spotify. Outros usuários podem ler e comentar. Apenas isso.

// stack

Frontend em HTML, CSS e JS.
Backend em Node.js com Express.
Banco de dados MySQL.
Música via Spotify Web API.

// inspiração

VA-11 Hall-A: Cyberpunk Bartender Action (Sukeban Games, 2016). Blogs pessoais na internet, principalmente pessoais. A vontade de ter um lugar quieto.
