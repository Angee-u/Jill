// sobre o bar

JILL-11.BAR

"Todo mundo que vem aqui tem uma história. Eu só fico aqui atrás servindo drinks e ouvindo."

// o que é isso

Um blog coletivo inspirado no universo de VA-11 Hall-A. Um lugar pra escrever sobre o dia a dia, tecnologia, arte e tudo que não cabe em outras redes. Sem algoritmo. Ordem cronológica.

// como funciona

Crie uma conta, escreva seus posts e opcionalmente adicione uma trilha sonora do Spotify. Outros usuários podem ler e comentar. Simples assim.

// stack

Frontend em HTML, CSS e JS puro.
Backend em Node.js com Express.
Banco de dados MySQL.
Música via Spotify Web API.

// inspiração

VA-11 Hall-A: Cyberpunk Bartender Action (Sukeban Games, 2016). Blogs pessoais dos anos 2000. Diários de madrugada. A vontade de ter um lugar só nosso na internet.
